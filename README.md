# get_a_IOT_job

Career tracker for Embedded, IoT, Real-Time and Critical Systems opportunities.

## Goals

- collect relevant job and internship opportunities;
- identify recurring market requirements;
- compare market demand with current skills;
- convert skill gaps into concrete learning projects;
- keep evidence of progress through GitHub projects.

## Target areas

- Embedded Software / Firmware
- Real-Time Systems / RTOS
- IoT
- Aerospace / UAS
- Automotive
- Medical Devices
- Safety-Critical Systems

## Workflow

1. Save an opportunity under `opportunities/`.
2. Extract the required skills and technologies.
3. Update `gap-analysis/market-baseline.md`.
4. Compare requirements against `gap-analysis/skills-gap.md`.
5. Create or prioritize a project under `project-ideas/`.
6. Turn finished projects into portfolio evidence.

## Current strategic project

UAS / AeroCup should be treated as a major portfolio project because it can provide evidence in embedded software, real-time systems, communications, integration, testing and aerospace engineering.
